# web development_level1_task3

The Temperature Converter Website is a simple web application that allows users to convert temperature values between different units such as Celsius, Fahrenheit, and optionally Kelvin.

The user enters a temperature value in the input field and selects the unit of the entered temperature from a dropdown menu. After clicking the Convert button, the application calculates the equivalent temperature in another unit and displays the result on the screen.

This project demonstrates the use of HTML, CSS, and JavaScript to create an interactive web application and internship at infobyte


## techologies Used:html,css,javascript
